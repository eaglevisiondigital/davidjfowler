BRAND ASSETS
------------
The site currently uses clean typographic brand treatments in the venture
cards instead of redrawing brand logos. This is intentional.

Exact approved brand references were located in the user's File Library for:
- Eagle Vision Digital EV/orbit branding
- Propel approved branding guidance
- Dustin Courageous DC shield
- Dave Fowler Signature Voice
- Lockliel

The File Library interface available in this build session exposes those as
references/previews, not exportable binary files, so the exact logo files
could not safely be copied into this downloadable build without recreating
them. Do NOT substitute AI-redrawn logos. When the original transparent PNG/SVG
files are placed in /assets, swap each typographic wordmark for the exact
approved image.

Recommended filenames:
assets/eagle-vision-capital-systems.svg
assets/eagle-vision-digital.svg
assets/eagle-vision-payments.svg
assets/propel.svg
assets/lockliel.svg
assets/dustin-courageous.svg
assets/dave-fowler-voice.svg
assets/the-boss.svg

PERSONAL PHOTO
--------------
No personal photo is required for this version. The hero is designed to work
without one. A strong approved portrait can later be added without changing
the content architecture.

DEPLOYMENT
----------
This is a static site. Drag the folder or ZIP into Netlify, or commit the files
to a GitHub repository connected to Netlify. No build command is required.
Publish directory: repository root.
